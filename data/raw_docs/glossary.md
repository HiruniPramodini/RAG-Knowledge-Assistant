# Aurelia Tech — Corporate Glossary & Abbreviations

> **Notice:** This document defines approved company acronyms, terminology, and key contacts for *Aurelia Tech*. Last updated: January 2026. Document Owner: Corporate Communications (`comms@aureliatech.com`).

---

## 1. Internal Terminology & Initiative Code Names

- **Project Atlas:** Aurelia's internal unified Client Success and account health analytics platform.
- **Project Horizon:** The corporate enterprise Data & AI initiative, encompassing churn prediction models and the internal RAG knowledge assistant.
- **Project Beacon:** Cross-cutting Platform Engineering initiative modernizing AWS infrastructure, containerization, and zero-downtime deployment pipelines.
- **PeopleConnect:** The internal self-service Human Resources portal used for submitting annual leave, viewing benefits, and expense claims.
- **Innovation Time:** The quarterly engineering program where 10% of engineering bandwidth is dedicated to self-directed technical prototypes and tooling improvements.
- **Aurelia Connect:** The official company VPN client software required for accessing internal enterprise infrastructure.

## 2. Common Acronyms & Abbreviations

- **ADR (Architecture Decision Record):** A standardized markdown document capturing an architectural decision, its rationale, and its trade-offs.
- **ARR (Annual Recurring Revenue):** Key business financial metric tracking contracted subscription revenue.
- **CI/CD (Continuous Integration / Continuous Deployment):** Automated pipeline practices for building, testing, and deploying code.
- **CSM (Client Success Manager):** Professional responsible for onboarding clients, driving product adoption, and managing retention.
- **EKS (Elastic Kubernetes Service):** AWS managed container orchestration platform running Aurelia services.
- **HPA (Horizontal Pod Autoscaler):** Kubernetes controller automatically scaling pod replicas up or down based on observed CPU and memory loads.
- **JIT (Just-In-Time) Access:** Security practice where elevated access credentials expire automatically after a designated task duration (e.g., 2 hours).
- **LGTM ("Looks Good To Me"):** Approval sign-off in GitHub pull request reviews indicating code is vetted for merging.
- **MDM (Mobile Device Management):** Software agent (Jamf/Intune) installed on company laptops ensuring disk encryption and security policy compliance.
- **MFA (Multi-Factor Authentication):** Mandatory secondary authentication method (Okta Verify or YubiKey) required for all corporate logins.
- **MTTR (Mean Time to Resolution):** Average duration required to resolve an IT incident or production outage.
- **OIDC (OpenID Connect):** Identity protocol layer built on OAuth 2.0 powering single sign-on across company web apps.
- **PTO (Paid Time Off):** Includes annual leave, sick leave, and floating cultural holidays.
- **RBAC (Role-Based Access Control):** Security authorization model assigning permissions to user roles rather than individual accounts.
- **SLA (Service Level Agreement):** Guaranteed turnaround timeframe for customer and internal IT support requests.
- **SOC 2 (System and Organization Controls 2):** Audited compliance standard demonstrating rigorous security, confidentiality, and data privacy controls.
- **SRE (Site Reliability Engineer):** Specialized software engineer focusing on infrastructure reliability, scalability, latency, and automated incident recovery.
